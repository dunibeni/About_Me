I started coding the website, but I realised that I didn't have a clear idea of what I wanted the design to look like. Because of this, I used Pixl's First Site as a starting point, as I really liked its centred layout.

I added a footer and a greeting, and chose a blue colour scheme. I used the Typed.js library to animate the greeting.

Later, I changed the styling because I wanted to create a glassmorphism effect. I think I managed to achieve the desired look. I downloaded the background image from Unsplash. At first, I couldn't get the glass effect to work on the `main` element, but eventually I found the cause: a single typo in the code.

Once the styling was mostly finished, I added the remaining text and a favicon. I then noticed that the images were missing from my GitHub upload. I initially tried to fix this directly on GitHub's website, but eventually deleted the incomplete upload and added the `images` folder to the project through VS Code instead.

Finally, I modified the animated greeting so that it now displays "Hello!", "Hali!", and "Hey!".

After finishing the website, I deployed it to Cloudflare, wrote the `README.md`, and then created the `Journal.md` file.
